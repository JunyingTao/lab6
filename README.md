# 11 Cafe
11 Cafe is a responsive cafe website created for CCT360 Lab 6.
## Pages
- Home: Featured drinks, image carousel, and menu cards.
- Contact: Contact form with required fields.
## Features
- Responsive navigation
- Image carousel
- Six product cards
- Expandable product details
- Product dialogs
- Contact form
## Technologies
- HTML5
- CSS3
- Bootstrap 6
- JavaScript (Bootstrap bundle)

- index.html
